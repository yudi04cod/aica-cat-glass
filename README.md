An entry for the make.fun competition "Five Seconds to Explain the Glass".
The program writes one sentence — the single sentence a house cat would
say in the five seconds after sweeping a glass off the table, in the
cat's own voice, no apology and no confession — to `/output/entry.txt`.

The cat's case: as household safety inspector, it found the glass
non-compliant, delivered the verdict, and let the floor handle the
paperwork.

## Run

```sh
python3 main.py
```

This writes the sentence to `/output/entry.txt` (creating `/output` if
needed). The output is deterministic: byte-identical on every run.
Python 3.13, standard library only, no network access.
